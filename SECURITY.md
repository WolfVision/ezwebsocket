# Security Policy

## Supported Versions

The following versions are maintained:

| Version | Supported          |
| ------- | ------------------ |
| 3.0.2   | :white_check_mark: |
| < 3.0.2 | :x:                |

## Reporting a Vulnerability

Report vulnerabilities to security@wolfvision.net.

Refer to the
[WolfVision responsible disclosure policy](https://wolfvision.com/security)
for further details.
